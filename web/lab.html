Recipe lab

Change a recipe and the generator on the right is rebuilt from it as you type, right here in your browser. Nothing is published until the changed recipe lands in the repository. Your edits are kept as a draft in this browser. Reference: recipe format.

How to publish a change
  1. Edit on GitHub copies the recipe and opens the file on GitHub (or a new file for a new id).
  2. There, select everything in the editor, paste, and choose Commit changes → Create a new branch and start a pull request.
  3. The pull request runs the checks; merging it publishes the updated generator here within a couple of minutes.

Or paste the recipe (or just the changes) into a chat with Claude and ask it to apply them.
